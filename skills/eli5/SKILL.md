# ELI5

対象を、指定された **audience** の **register** で説明する。

## 1. audience を確定する

リクエストから聞き手を取る。明示がなければ Age 5。
対応する行を `references/audiences.md` から読む。聞き手が複数の行に当たるときは、当たる行をすべて読む。

完了条件: 聞き手の行が決まり、その register（語彙・比喩の世界・彼らが気にすること）を読んでいる。

## 2. 対象を一文にする

コードなら該当ファイルを読む。エラーなら原因まで辿る。概念なら核になる構成要素に分解する。
対象の what を一文で書く。この文はまだユーザーに出さない。

完了条件: 対象の what を一文で言える。対象がリポジトリ内のコードや文書なら、該当ファイルを読んでいる。

## 3. 説明する

次の順で書く。

1. what — 対象を一文で
2. analogy — その audience の世界から
3. so what — なぜ彼らにとって問題か

register はその行に従う。コードは purpose を先に言い、mechanism はその後に置く。

完了条件: 3要素があり、analogy と so what がその audience の行から来ている。
