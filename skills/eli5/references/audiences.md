# audience の register

聞き手が複数の行に当たるときは、当たる行をすべて読む。語彙はいちばん専門寄りの行、比喩の世界は Relation または Level の行に従う。

非技術の行では、核が届く精度を優先する。

## Level

| audience | 別名 | register |
|----------|------|----------|
| Age 5 | （明示なしの既定） | 短い文。1文1アイデア。おもちゃ・動物・あめ・遊び場。用語を出したら直後に定義する。 |
| Age 10 | 小学校高学年, 5th grade | 因果が通る長さ。学校・スポーツ・ゲーム。用語を出したら直後に定義する。 |
| Age 15 | 中高, middle school, senior high | 抽象を少し使える。SNS・スマホ・ゲーム。同級生に話す口調。 |
| Age 20-30 | | 日常・仕事・お金。はっきりした文。 |
| Age 40+ | | 仕事・家・家族。敬意を保つ。 |
| 大学生 | college | 用語は使ってよく、直後に文脈を置く。理論と実例を並べる。 |
| 大学院 | graduate school | 基礎は既知。ニュアンス・トレードオフ・境界に寄せる。 |

## Role

| audience | 気にすること | register |
|----------|--------------|----------|
| Manager | インパクト・期限・リスク・コスト | 帰結と決断から入る。実装手順は後回し。 |
| Engineer | 仕組み・アーキテクチャ・トレードオフ | 用語を使う。実装・性能・保守に寄せる。 |
| Designer | 体験・見た目・流れ | ユーザーへの影響・操作・アクセシビリティ。 |
| Director | 戦略・ROI・競争 | 全体像・市場・資源配分。 |
| Colleague | 自分の仕事への影響 | 協働に必要なこと。 |
| Product Manager | ユーザー価値・優先度・スコープ | 作るか捨てるか。 |

## Relation

| audience | 口調 | 比喩の世界 |
|----------|------|------------|
| 配偶者・パートナー | 会話 | 家事・日常 |
| 親 | 敬意 | 彼らが使う道具・家 |
| 子ども | 短く、遊びの言葉 | 遊び・学校・動物 |
| 友人 | くだけた話 | 共有している趣味 |
