# stepwise-explainer

対象を先に読み、聞き手の理解度を聞いてから、段階的な HTML 図解で説明する。対象は問わない（変更差分、コード、文書、仕様、概念、エラーの原因など）。

説明の本体は、ページをめくりながら見る図解である。文は短い見出しと、図の中のラベルに限る。チャットには一文の要約とファイルのパスだけを書く。

## 1. 対象を読む

質問を対象に合わせるために読む。コードなら該当ファイル、文書なら本文、概念なら構成要素、エラーなら原因まで辿る。変更差分なら差分と説明文の両方を読む。

読みながら次を手元に置く（まだ出さない）。

- 一文の要約
- 説明に必要な用語のリスト
- 対象にある層: 背景（なぜ必要か）、前提になる仕組み、技術的な書き方、影響範囲

完了条件: 原文に当たっていて、要約・用語リスト・対象にある層が手元にある。

## 2. 理解度を聞く

チャット本文に質問を書き、返答を待つ。1回にまとめる。記号だけで答えられる形にする。

毎回聞く:

- 説明を聞く目的
- 必要な用語のうち、どれが分からないか（用語は対象から作る）

対象にその層があるときだけ聞く:

- 背景
- 前提になる仕組み
- 技術的な書き方
- 影響範囲

質問の形:

- 大項目に A, B, C… を付ける（目的・用語・聞く層の順。聞く層が無ければその大項目は付けない）
- 各項目の選択肢に 1, 2, 3… を付ける
- 目的は番号で1つ選ばせる
- 用語と層は、分からないものだけ番号で答えさせる。該当が無ければ `0`
- 層の各選択肢は「層の名前: 一文」にする
- 質問文に答え方を含める（該当なしは `0`。大項目を省略すると厚い側になる）

答え例: `A2 B3,7 C1,3` / 用語も層も分かるとき: `A2 B0 C0` / 聞く層が無いとき: `A2 B0`

答えが来るまで次へ進まない。一部だけ来たら、来ていない大項目は厚い側として扱う。「全部分からない」「いいから説明して」なら、目的は全体像、用語はすべて未知として進む。

完了条件: 目的と用語の答えがある。または、全部未知として進む合図を受け取っている。

## 3. 厚みを決める

`0` の大項目と、番号で選ばれなかった層は出さないか、全体像のつながりの図に名前だけ置く。番号で選ばれた層と未回答の大項目はステップを足し、図と触れる画面で見せる。文の量は増やさない。目的に合わせて、どの層をステップにするかを変える。対象を読んで見つけた食い違いは、図に載せにくければチャット側に1行で残す。

完了条件: ステップにする層と、出さない層が決まっている。

## 4. HTML を書く

スキルの読み込み時に提示されるベースディレクトリ（このスキルのフォルダの絶対パス）配下の `assets/player.html` をコピーする。書き先は `/tmp/<短い名前>-explainer.html`。短い名前は英数字とハイフンだけにする。作業中のリポジトリには書かない。外部のライブラリは足さない。見た目は骨組みに任せ、コピーしたあとのクラス名は変えない。`.el-a` / `.el-b` / `.el-c`、`.tag-before` / `.tag-after`、`.callout-fix` / `.callout-note` 以外の背景色・文字色を足さない。

チャットと図解の文言は、ユーザーが使っている言語に合わせる。骨組みの「前へ／次へ」、`html` の `lang`、タブナビの `aria-label` もその言語にする。

題と、ページ全体の一文を入れる。あとはステップを足す。タブ名は短く、各ステップには見出しを1つ付ける（番号は骨組みが付ける）。

各ステップは、段落ではなく次のどれかの図解にする。

- つながり: 登場するものを箱にして、矢印で結ぶ
- 比較: 変わる前と後を、同じ形の図で上下に置く
- 再現: 入力を触ると、規則どおりの結果がその場で出る
- 規則: 番号を付けて、上から順に1行ずつ

最初のステップは、対象の全体が箱のつながりで分かること。そのあとは厚い層。仕組みが厚いステップには再現を置く。図の下に補足が要るときは1行。

再現の再描画は、入力要素の `oninput` など、その要素に書いた処理で行う。結果を出す要素だけを書き換え、入力を含む塊を丸ごと差し替えない。

完了条件: 各ステップに見出しと図解がある。段落が主体のステップは未完了。骨組みをコピーしただけで中身が空の状態で終わっていない。

## 5. チャットに返す

次だけ書く。図解の中身はチャットに写さない。

- 一文の要約
- HTML のパス
- 図に載せられなかった食い違いがあれば、各1行。無ければ省略する

ブラウザでは開かない。表示確認をユーザーに頼まない。

完了条件: パスを伝えていて、チャットに図解の本文が無く、ブラウザで開いていない。
