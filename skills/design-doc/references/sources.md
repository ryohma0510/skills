# 設計書 — 参照資料

実行のたびに読み込む必要はない。詳しい説明が必要なときだけ参照する。

## 英文スタイル（段落・括弧・短文）

- [Google Technical Writing — Short sentences](https://developers.google.com/tech-writing/one/short-sentences)
- [Google developer documentation style guide — Parentheses](https://developers.google.com/style/parentheses)
- [Google developer documentation style guide — Paragraph structure](https://developers.google.com/style/paragraphs)

## 用語（語彙リストは増やさない）

用語の可否表や追加ルールはこのファイルにも `design-doc` にも置かない。
判断に迷ったときは `plain-vocab` スキルの「根拠」表（文化庁・国立国語研究所・デジタル庁）を参照する。
