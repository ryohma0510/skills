# サブエージェントによるレビュー

Agent ツールでサブエージェントを起動し、変更差分をレビューさせる。プロンプトは「今回実装した変更（diff）をレビューして、バグや改善点があれば指摘して」程度のシンプルな指示で十分——詳細なレビュー手順を書き下す必要はない。ただし、何を実装したか（タスクの概要）と、差分の見方（比較対象のブランチ・コミットなど）は伝えること。次のアクション（レビュー結果の表示）はこの結果に依存するため、`run_in_background: false` で起動し完了を待つ。

完了条件: サブエージェントからレビュー結果を受け取った。

## レビュー結果の表示

受け取った結果は、次の形式に整形してユーザーに提示する。

- 指摘がある場合: 深刻度順（High → Medium → Low）に箇条書きにし、各項目は `[深刻度] file:line — 要約 → 提案` の1行で表す。
- 指摘がない場合: 「レビューで問題は見つからなかった」の一行のみで終える。
- 冒頭に指摘件数の一言サマリを添える(例: 「指摘 2件（High 1 / Low 1）」)。
