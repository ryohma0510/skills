# 実装

実装作業では `tdd` スキルを使ってテストファーストで進め、コメントを書く・見直すときは `code-comments` スキルを使う。

## 実装後にレビューする

実装が完了したら、Agent ツールでサブエージェントを起動し、`review` スキルを実行させる。プロンプトには、何を実装したか（タスクの概要）と、差分の見方（比較対象のブランチ・コミットなど）を伝えること。次のアクション（レビュー結果の表示）はこの結果に依存するため、`run_in_background: false` で起動し完了を待つ。

完了条件: サブエージェントからレビュー結果を受け取った。
