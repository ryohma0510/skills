# レビューと修正のループ

自分が書いた差分をサブエージェントのレビューにかけ、指摘のうち確信度が高いものを自分で修正する。

## 1. 準備

差分の見方（比較対象の base ブランチ）と、何を実装したかのタスク概要を確定する。

完了条件: base ブランチとタスク概要が言語化できている。

## 2. ループを2周回す

次の1周を2回繰り返す。1周目で指摘がゼロでも2周目を回す。

1. Agent ツールでサブエージェントを起動し、`review` スキルを実行させる。プロンプトにはステップ1のタスク概要と base ブランチを伝える。この後の修正がレビュー結果に依存するため、`run_in_background: false` で起動して完了を待つ。
2. 指摘を鵜呑みにせず、1件ずつ自分で対応すべきかを判断する。該当箇所の差分とその周辺のコードを実際に読み、指摘のとおり壊れている・規約から外れていると確認できたものだけを「確信度が高い」とみなす。
3. 確信度が高い指摘を修正する。確信が持てない指摘は、判断の理由とともに報告に残す。
4. 修正したら、その差分を反映する。PR がある場合はコミットして push し、`pr-create` の更新モードで本文を最新の内容に合わせる。

完了条件: 2周を終え、各周のレビュー結果と、修正した指摘・見送った指摘がそれぞれ分かっている。

## 3. 結果の報告

2周分の指摘件数・修正した内容・見送った指摘とその理由を報告する。
