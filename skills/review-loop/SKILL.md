# レビューと修正のループ

自分が書いた差分をサブエージェントの `review` にかけ、指摘のうち確信度が高いものを自分で修正する。既定は 2 周。1 周目は Cursor の GPT（`gpt-5.6-sol-medium`）に渡し、2 周目はホスト側に戻す。ホスト自身が GPT 系なら 2 周目は Claude。

## 1. 準備

差分の見方（比較対象の base ブランチ）と、何を実装したかのタスク概要を確定する。

周回数は、呼び出し時に指定があればその数、なければ 2 周とする。

ホストが GPT 系かどうかは、自分のモデル名で決める。`gpt-5.6-sol` / `gpt-5.6-terra` / `codex` のいずれかを含めば GPT 系。分からなければ GPT 系ではない。

完了条件: base ブランチ・タスク概要・周回数・ホストが GPT 系かどうかが言える。

## 2. 各周のレビュアー

| 周 | ホストが GPT 系ではない | ホストが GPT 系 |
| --- | --- | --- |
| 1 | `gpt-5.6-sol-medium` | `gpt-5.6-sol-medium` |
| 2 | ホストと同じ（model を省略） | `claude-sonnet-5-thinking-medium` |
| 3 周目以降 | ホストと同じ | ホストと同じ |

指定したモデルが使えない、または起動に失敗した周は、ホストと同じサブエージェントに落とす。1 周目が落ちても 2 周目は表どおりもう一度試す。

起動の仕方:

- Cursor: Agent ツールでサブエージェントを起動し、上表の model を渡す。`run_in_background: false`。プロンプトで `review` スキルを実行させ、ステップ1のタスク概要と base ブランチを伝える。レビューのみで、ファイルは編集させない。
- Claude Code の 1 周目: `agent` が PATH にあれば `agent -p --mode ask --model gpt-5.6-sol-medium` に同じ指示を渡す。`agent` が無い、または失敗したらホストの Agent サブエージェント。2 周目は表どおり。

完了条件: 各周について、使ったレビュアー（表のモデルか、フォールバックしたホスト）が言える。

## 3. ループを回す

次の 1 周を、ステップ1で決めた回数だけ繰り返す。ある周で指摘がゼロでも、残りの周を回す。各周のレビュアーはステップ2。

1. ステップ2どおりサブエージェント（または `agent -p`）を起動し、完了を待つ。
2. 指摘を鵜呑みにせず、1件ずつ自分で対応すべきかを判断する。該当箇所の差分とその周辺のコードを実際に読み、指摘のとおり壊れている・規約から外れていると確認できたものだけを「確信度が高い」とみなす。
3. 確信度が高い指摘を修正する。確信が持てない指摘は、判断の理由とともに報告に残す。
4. 修正したら、その差分を反映する。PR がある場合はコミットして push し、`pr-create` の更新モードで本文を最新の内容に合わせる。

完了条件: 決めた回数の周を終え、各周のレビュアー・レビュー結果と、修正した指摘・見送った指摘がそれぞれ分かっている。

## 4. 結果の報告

周回数、各周のレビュアー（フォールバックしたならその旨）、指摘件数、修正した内容、見送った指摘とその理由を報告する。
