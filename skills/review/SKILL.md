# レビュー

変更差分をレビューし、バグや改善点があれば指摘する。CLAUDE.md・CONTEXT.md・lint 設定・既存コードのスタイルなど、リポジトリの規約があれば確認し、逸脱していないかも指摘対象に含める。

## 結果の表示

指摘は次の形式に整形して提示する。

- 指摘がある場合: 深刻度順（High → Medium → Low）に箇条書きにし、各項目は `[深刻度] file:line — 要約 → 提案` の1行で表す。
- 指摘がない場合: 「レビューで問題は見つからなかった」の一行のみで終える。
- 冒頭に指摘件数の一言サマリを添える(例: 「指摘 2件（High 1 / Low 1）」)。
